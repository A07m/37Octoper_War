# October 1973 War – Historical Data Analysis & Dashboard

## About the Project

This project presents a data-driven overview of the **October 1973 War**, using historical data and interactive visualizations to provide a clearer understanding of the conflict, its major events, and its human impact.

The goal of the project is to transform historical information into an accessible and visual format that makes the key facts easier to explore and understand.

## What the Dashboard Covers

* Major events and milestones during the war
* Timeline of the conflict
* Human losses and casualties
* Military operations and key developments
* Comparison of available historical figures
* Interactive charts and visualizations
* Geographical and historical context

## Tools & Technologies

* Power BI
* Microsoft Excel
* Data Analysis
* Data Visualization
* Data Cleaning
* Historical Data Research

## Project Highlights

The dashboard was designed to bring different pieces of historical information together in one interactive view.

It focuses on presenting the data clearly while maintaining the historical context behind the numbers.

## Purpose

This project combines **data analysis with historical research** to demonstrate how data visualization can be used to tell the story of an important historical event.

## Disclaimer

Historical figures and casualty estimates may vary between sources. The project presents the data based on the sources used during the research and is intended for educational and analytical purposes.
